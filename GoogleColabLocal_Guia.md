# INSTRUCCIONES PARA TENER JUPYTER NOTEBOOK EN LOCAL
Para poder tener notebooks en local y ejecutarlas desde VSC necesitamos:
## PASO 0 Instlar VSC SI NO LO TIENES
- Necesitas descargar e instalar VSC desde `https://code.visualstudio.com/download`

## PASO 1 Instalar Python
- Tener instalar Python, que podremos descargar desde `https://www.python.org/`, necesitamos la version 3.X.X o posterior.
- Luego necesitamos verificar si la instalacion es correcta y se reconoce a Python como comando interno del sistema con `python -V`.

## PASO 2 Instalar las extensiones necesarias sobre VSC
Para tener la misma experiencia que en Google Colab necesitamos instalar 3 extensiones necesarias:
- Python `https://marketplace.cursorapi.com/items/?itemName=ms-python.python`
- Jupyter `https://marketplace.cursorapi.com/items/?itemName=ms-toolsai.jupyter`
- Colab `https://marketplace.cursorapi.com/items/?itemName=Google.colab`


Una vez instalado todo esto podremos usar nuestro entorno VSC como Google Colab totalmente local.
